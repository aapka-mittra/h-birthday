Happy Birthday

A reusable birthday animation page built with HTML5, CSS3, and jQuery.

Technology Used: HTML5, CSS3, and jQuery

# Setup

From the project root, start a local static server:

## Python
```
python -m http.server 8081
```

Then visit http://localhost:8081 in your browser.

## Personalize the greeting

Edit the `birthdayName` constant near the top of `effect.js`. The balloons spell
the entered name (one balloon per letter, ignoring spaces), and the closing
greeting updates automatically.

## Node.js (optional)
```
npm install
npm run server-node
```

Then visit http://localhost:8081 in your browser.
